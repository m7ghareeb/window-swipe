# Security Policy

## Supported versions

Security fixes are made for the latest release of Window Swipe.

| Version | Supported |
|---|---|
| 1.0.x | Yes |

## Reporting a vulnerability

Please **do not** report security problems in public issues.

Use GitHub's private reporting instead: open the repository's **Security** tab and click
**Report a vulnerability**, or go directly to
<https://github.com/m7ghareeb/window-swipe/security/advisories/new>.

Please include what the problem is, how to reproduce it, and which versions of Window Swipe,
Cinnamon and your distribution are affected. You will get a reply as soon as possible. Once the
problem is understood, a fix will be prepared and released, and you will be credited if you wish.

## Scope

Window Swipe runs inside the Cinnamon desktop. It makes no network connections, runs no
external programs and writes no files apart from its settings, which Cinnamon stores. Reports
about Cinnamon, Muffin or Touchégg themselves belong to those projects.
